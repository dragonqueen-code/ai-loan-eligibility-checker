# AI Loan Eligibility Checker

## 1. Project Overview

The Loan Eligibility Checker is an educational web application that helps users explore basic loan and credit concepts. It includes a loan estimate, credit score guidance, an EMI calculator, and preset financial tips.

The project uses HTML5, CSS3, and JavaScript, with a dark glassmorphism-style interface. The current version does not connect to an AI service or make real lending decisions.

## 2. Project Objectives

- Help users estimate a loan EMI and debt-to-income ratio.
- Provide general credit score guidance.
- Calculate monthly loan installments.
- Share preset tips about responsible borrowing and financial planning.
- Present financial information in an accessible, responsive interface.

## 3. Key Features

### Loan Eligibility Estimate

Users enter their age, monthly income, existing EMIs, requested loan amount, interest rate, and loan tenure. The app calculates an estimated EMI and debt-to-income ratio using JavaScript.

The result is an educational estimate, not a loan approval.

### Credit Score Guide

Users select a sample credit score and repayment history to view general credit guidance. The guidance is illustrative and does not predict a lender’s decision.

### EMI Calculator

Calculates the estimated monthly installment, total interest, and total payable amount from the loan amount, annual interest rate, and tenure.

### General Financial Tips

Displays preset tips based on the user’s question. This feature is not connected to Claude or another AI service.

### User Interface

- Dark glassmorphism design.
- Organized sections and interactive forms.
- Responsive layout for desktop and mobile screens.
- Input validation and JavaScript calculations.

## 4. Technologies Used

- **HTML5:** Page structure and forms.
- **CSS3:** Styling, layout, and responsive design.
- **JavaScript:** Input handling, calculations, and interactive features.
- **Git and GitHub:** Source code management.
- **GitHub Pages:** Website hosting.
